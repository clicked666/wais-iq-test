# 韦氏智力测试 · 55 题在线版

基于韦氏智力量表（WAIS）风格的在线智力测评，纯静态实现，可直接部署到 GitHub Pages 与朋友分享。

## ✨ 功能

- **55 道题、5 大认知维度**：言语理解 VCI（7 题）· 视觉空间 VSI（10 题 × 60s）· 流体推理 FRI（16 题 × 60s，含 10 道瑞文式图形矩阵难题）· 工作记忆 WMI（12 题，含 8 道两阶段记忆题）· 加工速度 PSI（10 题 × 12s 冲刺）
- **计分**：难度加权正确率 → 分数曲线 `70 + 20p + 58p^1.8 + 3sin(πp)`（截断 [55,150]）→ FSIQ 为五维均值（截断 [70,158]），另输出 GAI、百分位（Φ 变换）与 WAIS 官方分级
- **图形矩阵题**：题目取自门萨挪威测试与国际 IQ Test 的高难题目，正确答案经逐题解题验证（门萨题选项图内嵌字母，不乱序）
- **结果页**：IQ 大数字、钟形曲线定位、五维认知档案条、分测验明细、作答有效性提示
- **上一题**：可跨分测验返回修改答案；限时题返回后重新计时，超时未改答则保留原答案
- **分享挑战**：一键复制带成绩的成绩链接（`#iq=分数&p=百分位`），好友打开即可看到挑战横幅
- **断点续测**：中途刷新/关闭浏览器后可从上次进度继续
- 纯前端零依赖，无需后端；作答有效性温和提示（作答过快/单一选项占比过高）

## 🚀 部署到 GitHub Pages（免费域名）

1. 在 GitHub 新建一个**公开仓库**（如 `wais-iq-test`，不要勾选初始化 README）。
2. 本目录执行：

   ```bash
   git init -b main
   git add .
   git commit -m "韦氏智力测试 50 题在线版"
   git remote add origin https://github.com/<你的用户名>/wais-iq-test.git
   git push -u origin main
   ```

3. 仓库页面 → **Settings → Pages** → Build and deployment → Source 选 **Deploy from a branch**，Branch 选 **main / (root)** → Save。
4. 一两分钟后访问免费域名：

   ```
   https://<你的用户名>.github.io/wais-iq-test/
   ```

   把这个链接发给朋友即可（结果页的"复制成绩链接"会自动带上该域名）。

> 想更省事：安装 GitHub CLI 后 `gh repo create wais-iq-test --public --source=. --push`，再执行第 3 步。

## ⚠️ 声明

本测试为**娱乐性质的韦氏风格测评**，非临床心理评估工具，结果不构成任何诊断依据。题目改编自公开风格的题库素材并经中文润色，仅供学习交流。
